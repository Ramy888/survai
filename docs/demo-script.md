# SurvAI demo script (3 minutes, written first; it decides what gets built)

1. 0:00-0:20 The problem: the real survey form and layout (blurred), "six people, one room, days".
2. 0:20-0:45 Capture: the prepared walk-through frames and the 25 s narrated path clip uploaded; SAM
   masks appear over racks and floor tiles.
3. 0:45-1:10 Layout: the draft on the tile grid; the engineer fixes one rack and confirms breakers.
4. 1:10-2:05 The meeting: round 1 statements stream in; Execution's R8 forced objection; Cooling asks
   for spare capacity; Room Manager asks "Does rack R3 hold access devices?"; the engineer answers;
   round 2 the Lead moves the reserved rack, agents react to each other, all approve.
5. 2:05-2:35 Report and layout: the mirrored form, hatched reserved area, cable paths with lengths;
   print to PDF.
6. 2:35-2:50 A department representative approves from a phone link.
7. 2:50-3:00 Meta models used, and the public replay link with "run the meeting again".


Demo device: Juniper MX104.
